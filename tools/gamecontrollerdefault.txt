# gamecontrollerdefault.txt - GoldenEye PC port controller LAYOUTS
#
# Lives next to ge.exe (like gamecontrollerdb.txt). Add your own lines, share
# the file. Both the game and GE Launcher read it:
#   - the game seeds a newly connected pad with the FIRST layout whose match
#     holds (top to bottom - put specific pads above generic ones);
#   - the launcher lists every layout in its Controls > Layout dropdown, and
#     "Reset to built-in map" returns to the game's pick.
#
# One layout per line, three fields separated by '|':
#
#   Name | match terms | key=value; key=value; ...
#
# match terms (comma separated, ALL must hold):
#   type=xbox | type=ps | type=switch | type=any     SDL controller type
#   name=<exact SDL controller name>                 as shown by the launcher
#   name~<substring>                                 part of the name
#   noxy                                             pad has no X / Y buttons
#   n64                                              this layout is played on the N64
#                                                    control styles: an N64 controller
#                                                    or derivative (NSO, 8BitDo 64,
#                                                    ModRetro M64, a USB adapter), or
#                                                    a modern pad on its Standard
#                                                    (console) mapping.
#                                                    ONLY these get the N64 control
#                                                    styles (1.1-2.4) and the N64
#                                                    bindings; everything else binds
#                                                    Port inputs, which drive movement
#                                                    and look directly. Add it to your
#                                                    own line for a derivative we have
#                                                    not heard of. A line that puts the
#                                                    C buttons on a stick and binds no
#                                                    Look stick MUST carry it - port
#                                                    mode turns only from the Look
#                                                    stick.
#
# values are SDL control names, so one layout fits every pad SDL maps:
#   buttons: a b x y back guide start leftstick rightstick leftshoulder
#            rightshoulder dpup dpdown dpleft dpright misc1 touchpad paddle1-4
#   axes:    leftx+ leftx- lefty+ lefty- rightx+ rightx- righty+ righty-
#            lefttrigger righttrigger          (sticks: + = right / down)
#   or a raw token for a control SDL does not name: b8, a4+, h0u
#   "x,y" = one action on several inputs. Keys you leave out are unbound.
#
# keys:
#   sticks    stick_x stick_y (Move)  look_x look_y (Look, twin stick)
#   digital   move_up move_down move_left move_right look_up look_down look_left look_right
#   N64       a b z start l r c_up c_down c_left c_right dpad_up dpad_down dpad_left dpad_right
#             (a = change weapon, b = use/reload, z = fire, r/l = aim)
#   Port      reload use walk run walk_toggle prev_weapon next_weapon
#             prev_inventory next_inventory crouch_toggle crouch_hold
#             watch_prev watch_next watch_up watch_down watch_objectives
#
# Remember: Move stick = stick_x/y, Look stick = look_x/y; with a Look stick
# bound the port drives the pad twin-stick, and a layout with the C buttons on
# the right stick instead carries n64 and plays the N64 styles.
#
# STANDARD AND PRO (murkantor 2026-09-17). Every modern controller gets a PAIR:
#   <pad> Pro       twin stick, and every PC convenience bound - reload,
#                   weapon cycling, gadget cycling, crouch, objectives.
#                   This is what the port has always shipped.
#   <pad> Standard  murkantor's layout (2026-10-13, his saved "Xbox Standard
#                   Default" made built in): twin stick, Port-driven, the
#                   N64 face positions kept - Y next weapon, A use / accept,
#                   B next gadget / back, X reload, LS click crouch
#                   toggle, RB detonate, LB Classic
#                   Mode. The N64 rows are filled in too (the console
#                   mapping, C on the right stick) for a pad switched to N64
#                   mode. PlayStation is the same by position; Switch is
#                   translated by position (SDL names Switch buttons by
#                   their LABEL, so the bottom button is b there).
# STANDARD is listed FIRST of each pair (murkantor 2026-10-13: "the Xbox Standard
# layout that's default for all players, and the Pro is a built in
# alternative"), so a pad nobody has chosen for seeds Standard. Switch Pro
# is Xbox Pro translated by position, like Switch Standard. A player's
# choice is remembered per slot as midas.ini padN_layout=<name> and beats this
# order.
#
# The N64-adapter layouts below are not paired: an N64 pad has only N64
# controls, so its Standard and its Pro would be the same line.
